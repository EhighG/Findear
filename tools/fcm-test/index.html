Findear FCM 웹푸시 테스트

현재 origin:

설정 안내

  1. Firebase 콘솔에서 새 프로젝트를 만들고 웹 앱을 추가한다 (프로젝트 설정 → 일반 → 웹 앱의 firebaseConfig).
  2. firebase-config.example.js를 firebase-config.js로 복사해 firebaseConfig 값과 VAPID 공개키(프로젝트 설정 → 클라우드 메시징 → 웹 푸시 인증서)를 채운다. 이 파일은 git에서 제외된다.
  3. 서버: 서비스 계정 키를 secrets/firebase-adminsdk.json에 두고 .env에 FCM_ENABLED=true를 설정한다. main은 local 프로필이어야 한다 (/members/login, /alarm/send-fcm이 local 전용).
  4. 이 페이지는 반드시 http://localhost:5500으로 연다. 127.0.0.1은 다른 origin이라 main의 CORS(CORS_ALLOWED_ORIGINS)에 걸린다.
  5. 자세한 절차는 tools/fcm-test/README.md를 본다.
